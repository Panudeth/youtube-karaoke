# Karaoke Live: รายละเอียดทางเทคนิค

(เอกสารฉบับเต็ม สำหรับวิธีใช้แบบสั้นดู README.md ที่หน้าแรก)

โปรแกรมฟังเพลงจาก YouTube แบบสด แล้วตัดเสียงร้องออกด้วย AI (Demucs) บน GPU
วาง URL เพลงหรือ playlist กดเล่น รอไม่กี่วินาที เสียงร้องหายทันที เพลงถัดไปใน playlist ถูกเตรียมล่วงหน้าระหว่างฟัง

## วิธีใช้แบบ Extension (แนะนำ: ใช้หน้า YouTube ปกติ login ได้ เล่น playlist ได้)

1. ดับเบิลคลิก `run.bat` ให้ server รันไว้ (ต้องเปิดค้างไว้ตลอดที่ใช้)
2. ติดตั้ง extension ครั้งเดียว
   - Chrome: เปิด `chrome://extensions` / Edge: เปิด `edge://extensions`
   - เปิด **Developer mode** มุมขวาบน
   - กด **Load unpacked** แล้วเลือกโฟลเดอร์ โฟลเดอร์ `extension` ของโปรเจกต์
3. เปิด youtube.com ตามปกติ กดเพลงหรือ playlist อะไรก็ได้
   - มุมขวาล่างจะมีแผง 🎤 Karaoke Live แสดงสถานะ ปุ่มเปิด/ปิด และ slider เสียงร้อง
   - ครั้งแรกที่เปิดแท็บต้องคลิกที่หน้าเว็บหนึ่งครั้ง (กดเล่นก็นับ) extension จึงจะเข้าควบคุมเสียงได้ เป็นข้อบังคับของเบราว์เซอร์
   - บรรทัดเล็กใต้สถานะคือข้อมูลวินิจฉัย ถ้ามีปัญหาส่งข้อความบรรทัดนี้มาได้เลย
   - ถ้าโหลดเสียงที่แยกไม่ได้ extension จะสลับกลับไปเสียงต้นฉบับเองภายใน 4 วินาที ไม่ทิ้งให้เงียบ
   - เพลงที่ยังไม่เคยแยก วิดีโอจะหยุดรอประมาณ 5 วินาทีจนเสียงช่วงแรกพร้อม แล้วเล่นต่อเอง
   - ใน playlist เพลงถัดไป 3 เพลงจะถูกเตรียมล่วงหน้า พอ autoplay ไปเพลงถัดไปจะเล่นได้ทันที
   - ระหว่างโฆษณาจะได้ยินเสียงต้นฉบับตามปกติ
4. คลิกที่หัวแผงเพื่อย่อ/ขยาย ปุ่ม "เปิดอยู่/ปิดอยู่" สลับกลับไปเสียงต้นฉบับได้ทันที

วิดีโอส่วนตัว (private) หรือ members-only: server ต้องใช้ cookie ของเบราว์เซอร์ ให้ตั้ง environment variable
`KARAOKE_COOKIES_BROWSER=firefox` (หรือ `edge`, `chrome`) ก่อนรัน server หมายเหตุ Chrome/Edge รุ่นใหม่บน Windows
เข้ารหัส cookie ไว้ yt-dlp อาจอ่านไม่ได้ Firefox ใช้ได้แน่นอนกว่า

## วิธีใช้แบบหน้าเว็บของโปรแกรมเอง (วาง URL ทีละเพลง/playlist)

1. ดับเบิลคลิก `run.bat` (หรือรัน `run.ps1`) จะเปิด server ที่ http://127.0.0.1:8765 และเปิดเบราว์เซอร์ให้อัตโนมัติ
2. วาง URL YouTube (วิดีโอเดี่ยว หรือ playlist) ในช่องด้านบน แล้วกด Enter
3. กดเพลงในรายการด้านขวาเพื่อเล่น
4. เลื่อน slider **เสียงร้อง** เพื่อปรับระดับเสียงร้อง (0% = ตัดออกหมด, 100% = เสียงเต็ม)
5. กด Space เพื่อเล่น/หยุด คลิกบนแถบเวลาเพื่อเลื่อนตำแหน่ง

รายการเพลงถูกจำไว้ในเบราว์เซอร์ และเพลงที่เคยแยกแล้วถูก cache ไว้ในโฟลเดอร์ `cache/` เปิดครั้งต่อไปเล่นได้ทันที

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `server.py` | FastAPI: รับ URL, ดาวน์โหลดเสียงด้วย yt-dlp, จัดคิวแยกเสียง, ส่ง chunk เสียง |
| `separator.py` | เรียก Demucs (htdemucs) แยกเสียงร้อง/ดนตรี ทีละช่วง 10 วินาที |
| `static/index.html` | หน้า player: Web Audio API เล่น chunk ต่อเนื่อง, sync วิดีโอ YouTube (ปิดเสียง), slider เสียงร้อง |
| `extension/content.js` | Browser extension: ดึงเสียง `<video>` ของ YouTube เข้า Web Audio เพื่อปิดเสียงต้นฉบับ แล้วเล่น chunk ที่แยกแล้วตาม `video.currentTime` |
| `extension/bg.js` | Service worker เป็นตัวกลางเรียก server (หน้า youtube.com เรียก 127.0.0.1 ตรงไม่ได้) |
| `lyrics.py` | คำร้อง: subtitle ของ YouTube, Whisper แบบ batch, ตัดคำไทย (PyThaiNLP), align ข้อความกับเวลา, ตัดบรรทัด |
| `cache/<การตั้งค่า>/<video_id>/` | chunk ที่แยกแล้วเป็น Ogg/Opus (`cXXXX_acc.ogg` = ดนตรี, `cXXXX_voc.ogg` = เสียงร้อง), `vocals.wav`, `lyrics.json` |

## คำร้อง (lyrics)

ทุกเพลงจะได้คำร้องอัตโนมัติ แสดงเป็น overlay บนวิดีโอ (ทั้งใน extension และหน้าเว็บของโปรแกรม)
ไฮไลต์บรรทัดปัจจุบันและไล่สีตามคำ

ขั้นตอน (เพลงใหม่ 4 นาที ใช้เวลารวมประมาณ 20-30 วินาที บน RTX 3070, เพลงถัดไปใน playlist เตรียมล่วงหน้าจึงไม่ต้องรอ)

1. ดึง subtitle ที่ช่องอัปโหลดเองทันที (ถ้ามี) แสดงได้ก่อนแบบแบ่งบรรทัดตามสัดส่วนตัวอักษร
2. แยกเสียงร้องด้วย Demucs (~10 วินาที) แล้ว Whisper ถอด track เสียงร้องแบบ batch (~6 วินาที) ได้ timestamp ระดับคำ
3. ถ้ามี subtitle: นำ **ข้อความจาก subtitle** (ถูกต้อง) มาจับคู่กับ **เวลาต่อคำจาก Whisper** ด้วยการ align ระดับตัวอักษร ได้ทั้งคำถูกและจังหวะแม่น
   ถ้าไม่มี: ใช้ข้อความจาก Whisper (ภาษาไทยใช้โมเดล Thonburian Whisper ที่ fine-tune ภาษาไทย)
4. ตัดคำภาษาไทยด้วย PyThaiNLP แล้วตัดบรรทัดตามจังหวะหยุดหายใจ ไม่เกิน ~34 ตัวอักษรหรือ 5.5 วินาทีต่อบรรทัด

บนแผงของ extension

- **รอให้พร้อมก่อนเล่น** (เปิดเป็นค่าเริ่มต้น) วิดีโอหยุดรอจนเสียงและคำร้องพร้อม แล้วเล่นเอง กดเล่นระหว่างรอเพื่อข้ามได้
- **ภาษา** เลือกเองถ้าระบบตรวจภาษาผิด เปลี่ยนแล้วระบบถอดใหม่ทันที
- **ถอดคำร้องใหม่ (AI)** ไม่สนใจ subtitle ของ YouTube ถอดจากเสียงร้องล้วนๆ (ใช้เมื่อ subtitle เป็นคำแปล)

ตั้งค่าใน `run.bat`: `KARAOKE_LYRICS=0` ปิดระบบคำร้อง, `KARAOKE_WHISPER_TH_MODEL=` (ว่าง) ปิดโมเดลไทยเพื่อประหยัด VRAM ราว 1.6GB,
`KARAOKE_LANG=th` บังคับภาษาทุกเพลง, `KARAOKE_WHISPER_BEAM=5` แม่นขึ้นเล็กน้อยช้าลงเล็กน้อย (ค่าเริ่มต้น 3)
VRAM รวม Demucs + Whisper 2 โมเดล (int8) ประมาณ 5GB ตอนว่าง

ข้อจำกัด: เพลงที่ไม่มี subtitle จะได้ข้อความจาก Whisper ซึ่งถอดเสียงร้องเพลงไทยได้ราว 70-85% ของคำ ท่อนเร็วหรือร้องประสานผิดมากขึ้น
ผลลัพธ์ cache ไว้ใน `cache/<การตั้งค่า>/<video_id>/lyrics.json` แก้เองได้

## ปรับคุณภาพเสียง

แก้ค่าที่หัวไฟล์ `run.bat` (หรือ `run.ps1`) แล้วรันใหม่ แต่ละการตั้งค่ามี cache แยกกันใน `cache/<ชื่อการตั้งค่า>/`
เพลงที่เคยแยกด้วยค่าเก่าจะถูกแยกใหม่ในครั้งแรก

| ตัวแปร | ค่า | ผล |
|---|---|---|
| `KARAOKE_MODEL` | `htdemucs` (ค่าเริ่มต้น) | เร็ว เพลง 4 นาทีแยกเสร็จใน ~10-15 วินาที |
|  | `htdemucs_ft` | สะอาดขึ้นเล็กน้อย ช้ากว่าราว 4 เท่า (เพลง 4 นาที ~40 วินาที) |
| `KARAOKE_ACCOMP` | `mix_minus_vocals` (ค่าเริ่มต้น) | ดนตรี = ต้นฉบับ ลบ เสียงร้องที่โมเดลหาได้ รายละเอียดดนตรีครบ อาจมีเสียงร้องรั่วเบาๆ |
|  | `sum_stems` | ดนตรี = กลอง+เบส+อื่นๆ ที่โมเดลสร้างใหม่ เสียงร้องหายเกลี้ยงกว่า แต่ดนตรีทึบกว่า |
| `KARAOKE_SHIFTS` | `0` (ค่าเริ่มต้น) / `1` / `2` | ประมวลผลหลายรอบแบบเลื่อนเวลาแล้วเฉลี่ย ดีขึ้นเล็กน้อย ช้าขึ้นตามจำนวนรอบ |

ถ้า GPU ไม่ทัน (วิดีโอหยุดรอบ่อย) ให้กลับไปใช้ `htdemucs` หรือลด `KARAOKE_SHIFTS` เป็น 0

## ติดตั้งใหม่ (ถ้าย้ายเครื่อง)

```
python -m venv .venv
.venv\Scripts\pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu124
.venv\Scripts\pip install -r requirements.txt
winget install Gyan.FFmpeg
```

## ข้อจำกัด

- ต้องมี GPU NVIDIA (ทดสอบบน RTX 3070: เพลง 4 นาที เสียงเริ่มได้ใน ~7 วินาที แยกเสร็จ ~18 วินาที คำร้องพร้อม ~25 วินาที)
- ถ้า YouTube เปลี่ยนระบบ ให้อัปเดต yt-dlp: `.venv\Scripts\pip install -U yt-dlp`
- วิดีโอบางตัวไม่อนุญาตให้ฝัง (embed) จะแสดงเฉพาะเสียงกับภาพปก
- ใช้ส่วนตัวเท่านั้น การดาวน์โหลดเสียงจาก YouTube ขัดกับข้อกำหนดการใช้งานของ YouTube
